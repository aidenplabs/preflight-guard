# Security

This project is a small heuristic scanner, not a hosted security service.

## Reporting a problem

If you find:
- an accidental secret in the repo
- a workflow or example that exposes something sensitive
- a bug that could mislead users badly about scanner output

please open a private report if possible, or contact the maintainer before opening a public issue.

## Scope

This file is about repo and release hygiene.

It is not a promise that the scanner can:
- prove apps are safe
- catch every security issue
- provide full vulnerability handling for downstream apps
